# 📊 Educational Revenue Analytics

## 📌 Project Overview

Educational Revenue Analytics is a Power BI business intelligence project designed to analyze course enrollments, invoice transactions, revenue performance, payment methods, and course popularity across regions and colleges.

The dashboard transforms educational transaction data into meaningful insights to help an institution understand enrollment patterns, monitor revenue, and make data-driven business decisions.

## 🎯 Project Objectives

- Analyze student enrollments across different courses.
- Monitor invoice transactions and revenue performance.
- Understand payment method distribution, including Cash, UPI, and Card.
- Analyze course popularity across different regions.
- Identify popular courses among colleges.
- Explore enrollment and revenue trends over time.
- Present key findings and recommendations through an interactive dashboard.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** — interactive dashboard development
- **Power Query** — data cleaning and transformation
- **DAX** — calculations and analytical measures
- **Microsoft Excel** — source data preparation
- **SQL** — transaction analysis and data querying
- **Python** — data analysis and preparation, where applicable
